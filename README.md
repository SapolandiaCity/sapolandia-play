# SAPOLANDIA PLAY · SPL.GOOV

Plataforma de jogos com identidade própria: tema premium claro-escuro, 20 slots originais
SPL.GOOV com reels animados, rodadas grátis, bônus de boas-vindas, depósito Pix e painel administrativo.

## Módulos

| Módulo | Estado |
|---|---|
| Banner e popup de lançamento | Funcional |
| Cadastro com 5 campos + bônus de R$ 30 | Funcional, único por conta |
| Login / perfil / avatar / configurações | Funcional |
| Catálogo, busca, categorias, favoritos | Funcional |
| 20 slots 5x3 com 10 linhas | Funcional |
| Reels animados, partículas, autogiro, velocidade | Funcional |
| GOOV BÔNUS — rodadas grátis com multiplicador | Funcional |
| Depósito Pix (R$ 10 / 20 / 30) | Funcional, sem crédito automático |
| Saque | Bloqueado por manutenção |
| Painel administrativo | Funcional (senha `goov2026`) |
